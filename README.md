# The Digital Translator

## Project Overview

This project explores how real-world problems can be translated into precise instructions, algorithms and computer programs.

## Project Tiers

### Tier 1 – The Literal Assistant
Writing precise instructions for preparing breakfast.

### Tier 2 – Algorithm Thinking
Designing an algorithm for withdrawing money from an ATM.

### Tier 3 – Input, Processing and Output
Understanding how a calculator receives input, processes information and produces output.

### Tier 4 – Data Translator
Understanding data types and digital representation.

### Tier 5 – System Architecture
Explaining how an online store processes and stores customer orders.

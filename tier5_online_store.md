# Tier 5: Architecture Challenge – The Online Store

## Scenario

A customer orders a product from an online store.

## 1. Customer Input

The customer provides:
- Product name
- Quantity
- Delivery information
- Payment information

These details are the input data.

## 2. Application / Program

The online store application receives the customer's information and contains instructions for processing the order.

## 3. Instructions

The program instructs the computer to:
- Identify the selected product.
- Check product availability.
- Calculate the order total.
- Process the order information.
- Update the relevant records.

## 4. Data Processing

The computer processes the information.

Example:

Product price: ₦50,000  
Quantity: 2  

Order total: ₦100,000

## 5. Stored Data

The system stores information such as:
- Customer details
- Product
- Quantity
- Order amount
- Order status

This allows the system to remember the order.

## 6. Result / Output

The system displays a confirmation:

"Order confirmed. Total: ₦100,000."

### Questions

**What is the computer doing?**

It processes the customer's information by following the program's instructions.

**What is the program doing?**

It tells the computer how to handle the customer's order.

**What data is involved?**

Customer details, product, quantity, delivery information and payment information.

**What instructions are being executed?**

Checking product availability, calculating the total, processing the order and updating records.

**What is the output?**

An order confirmation showing the total amount.

**What information needs to be stored?**

Customer details, product, quantity, order amount and order status.

## Final Reflection

A computer does not understand the real world directly. It works with digital representations of information and follows instructions to process that information and produce results.

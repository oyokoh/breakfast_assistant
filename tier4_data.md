## Customer Information

| Information | Data Type | Value |
|---|---|---|

## Digital Representation

Computers represent information using digital data.

- Text is represented using character encoding.
- Numbers are represented using numerical formats.
- Boolean values represent True or False states.
- Ultimately, digital information is represented using binary (0s and 1s).

## Reasoning Challenge

If the account balance is stored incorrectly, the customer may see an incorrect balance. This could lead to incorrect financial transactions and account records.

## Conclusion

Data representation allows computers to store, process and communicate different kinds of information correctly.
